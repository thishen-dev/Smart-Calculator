# 🧮 Smart Calculator

A modern web-based calculator built with **HTML5, CSS3, and JavaScript**, featuring mathematical expression evaluation, keyboard controls, and high-precision calculations powered by Math.js.

---

## ✨ Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Square root calculations
- Decimal number support
- High-precision arithmetic using Math.js BigNumber
- Real-time expression display while entering calculations
- Backspace and clear functionality
- Keyboard support for convenient input
- Input validation and error handling
- Interactive buttons with smooth hover effects

---

## 🛠️ Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling, layout, and animations
- **JavaScript** — Application logic and event handling
- **Math.js** — Mathematical expression evaluation and high-precision arithmetic
- **Git & GitHub** — Version control and source code management

---

## 🖥️ User Interface

The interface uses a soft blue and purple gradient background, a white calculator card, a clear numerical display, and rounded buttons with a consistent blue color scheme.

## ⚙️ Getting Started

### Prerequisites

- A modern web browser
- An internet connection to load Math.js from its CDN

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/thishen-dev/Smart-Calculator.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Smart-Calculator
   ```

3. Open `index.html` in your web browser.

No additional installation is required.

---

## ⌨️ Keyboard Controls

| Key | Action |
|---|---|
| `0–9` | Enter numbers |
| `+`, `-`, `*`, `/` | Enter operators |
| `.` | Enter decimal point |
| `Enter` | Calculate the result |
| `Backspace` | Delete the last character |
| `Escape` | Clear the display |
| `R` | Enter the square root symbol |
