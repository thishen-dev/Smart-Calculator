# 🧮 Smart Calculator

A simple, interactive calculator built using HTML, CSS, and JavaScript, with Math.js for mathematical calculations.

## ✨ Features

- Basic arithmetic operations (+, −, ×, ÷)
- Square root calculations
- Decimal number support
- Backspace to delete the last character
- AC button to clear the display
- Keyboard support
- High-precision calculations using Math.js
- Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- [Math.js](https://mathjs.org/)

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/thishen-dev/Smart-Calculator.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.
