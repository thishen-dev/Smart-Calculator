# 🧮 Smart Calculator

A web-based calculator built using **HTML5, CSS3, and JavaScript**, with Math.js for evaluating mathematical expressions.

---

## 🚀 Live Demo

**Try it here:** [Smart Calculator](https://thishen-dev.github.io/Smart-Calculator/)

---

## ✨ Features

- ➕ Basic arithmetic operations: addition, subtraction, multiplication, and division
- √ Square root calculations
- 🔢 Decimal number input
- ⌨️ Keyboard support for numbers and operators
- ⏎ Calculate results using the Enter key
- ⌫ Delete the last character using Backspace
- 🧹 Clear the display using the AC button or Escape key
- ⚠️ Displays an error message when a calculation fails
- 🎨 Blue and purple gradient background with rounded buttons and hover animations

---

## 🛠️ Technologies Used

- **HTML5** — Calculator structure
- **CSS3** — Styling and layout
- **JavaScript** — Calculator logic and event handling
- **[Math.js](https://mathjs.org/)** — Mathematical expression evaluation
- **Git & GitHub** — Version control and project hosting

## ⚙️ How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/thishen-dev/Smart-Calculator.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

**Note:** An internet connection is required to load Math.js from its CDN.

---

## ⌨️ Keyboard Controls

| Key | Action |
|---|---|
| `0–9` | Enter numbers |
| `+`, `-`, `*`, `/` | Enter operators |
| `.` | Enter a decimal point |
| `Enter` | Calculate the result |
| `Backspace` | Delete the last character |
| `Escape` | Clear the display |
| `R` | Enter the square root symbol |
